## About this entry

This entry is a trophy guide and progress tracker for Grand Theft Auto VI that runs entirely offline in the browser — open it, and nothing is fetched from the network.

It lists all 55 PS5 trophies with their official names, descriptions and grades (bronze, silver, gold and the platinum), so you can see the full set at a glance and plan around it. Every trophy carries its own short guide, written for this entry, with a citation pointing to the source it draws on, which makes each tip easy to check rather than something you have to take on trust.

Trophies that can be missed are flagged as missable, so you know which ones to watch for before a point of no return. A platinum roadmap ties the set together into an order of attack: what to pick up during the story, what to clean up afterwards, and where the long grinds are best started early.

As a tracker, it keeps a checklist of the trophies you have earned. Your progress is saved in the browser, and the checklist can be exported to a file and imported again, so a run can be backed up, moved to another machine, or shared. Filters let you narrow the list — by grade, by earned or unearned, by missable, and by text search — and a spoiler setting hides the details of trophies you would rather discover in the game itself.

The guide uses no Rockstar artwork or logos; its presentation is plain text, layout and styling created for this entry.
